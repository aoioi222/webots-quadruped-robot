# HAL 三模态机器人仿真

打开 `worlds/my_firstwebots.wbt`。该场景以 5 ms 推进物理仿真，控制器在每个 HAL 周期按仿真时间唤醒，当前控制频率为 200 Hz。

`Makefile` 直接从同一桌面目录下的 `HAL/RCS_Template_F407/RCS/user/robot` 编译任务主循环、步态、贝塞尔轨迹、正逆运动学、摆动失败保护、姿态控制、跳跃、SBUS 解码与遥控事件分发。修改 HAL 源码后，在 Webots 中重新编译控制器并重置仿真即可。HAL 工程移到其他位置时，用 `HAL_ROBOT_DIR` 指定新的 `RCS/user/robot` 目录。控制器目录根部的旧 Webots 源码保留作参考。

在 PowerShell 中也可以从本目录编译。

```powershell
$env:Path = "$env:WEBOTS_HOME\msys64\mingw64\bin;$env:WEBOTS_HOME\msys64\usr\bin;$env:Path"
& "$env:WEBOTS_HOME\msys64\usr\bin\make.exe" -j4
```

启动后点击 3D 视图，按 `I` 进入站立或 `O` 启动步态。

| 按键 | 功能 |
| --- | --- |
| `I` / `O` | 站立 / 启动步态 |
| `1` / `2` | 从轮式切回四足 / 进入轮式 |
| `3` | 进入足式爬坡模式 |
| `4` / `5` / `6` | Walk / Trot / Pronk |
| `W` / `S` | 前进 / 后退 |
| `A` / `D` | 四足横移，轮式转向 |
| `Q` / `E` | 左转 / 右转 |
| `R` | 按住让虚拟摇杆回中 |
| `↑` / `↓` | 增减速度倍率 |
| 空格 / `F` | 跳跃 / 切换折叠 |
| `H` / `Esc` | 按住触发 HAL 急停档 / 关机 |

移动键松开后，虚拟摇杆回中。键盘模拟 SBUS 开关换档。跳跃需先启动四足步态，轮式需先通过 `I` 或 `O` 唤醒。轮式换回四足用 `1`，轮式折叠后再用 `1`、`2` 可重新产生轮式档切换。

按 `3` 可直接进入足式爬坡，按住 `W` 向车头方向攀爬。爬坡采用四拍单腿摆动，机身随触地点拟合的坡面调整俯仰和前后重心，并在抬腿时给髋关节保留行程。松开方向键后停止发起新的摆动，按 `4`、`5` 或 `6` 可切回普通步态。

场景中的机器狗由 v11.1 URDF 转成独立的 `QuadrupedV11_1` PROTO。电机名称由关节类型 `HAA`、`HFE`、`KFE`、`WHEEL` 和腿号 `FR`（右前）、`FL`（左前）、`RR`（右后）、`RL`（左后）组成，例如 `KFE_FR`。每个位置传感器的名称为电机名加 `_sensor`。模型的 +X 朝前，+Y 朝左。Webots 沿用旧场景的腿形。髋俯仰正角使大腿后倾，膝关节正角使小腿向前收。

`hal_webots/quadruped_v11_1_config.h` 为 Webots 构建提供仿真的机械尺寸、姿态限位和电机参数。仿真与 HAL 共用步态和跳跃代码。步态足端为轮胎中线相对水平地面的最低点，触地点和重力方向均使用机体坐标。轮式悬挂使用轮心正逆解。仿真轮半径为 40 mm，HAL 使用 `robot_config.h` 中的实机轮径配置。轮胎接触使用较低的侧向摩擦，允许四轮差速转弯。

腿关节使用灵足 EduLite05 的 1.8 N·m 额定扭矩和 6.0 N·m 峰值扭矩，轮毂使用达妙 DM-H6215 的 1.0 N·m 额定扭矩和 2.0 N·m 峰值扭矩。Webots 每 5 ms 用扭矩反馈积分超额负载，降到额定扭矩以下后逐渐恢复峰值余量。由额定转速至空载转速的线性降额和峰值余量是仿真近似，详细参数见 [运控建模参数](../../urdf/运控建模参数.md)。

Webots 腿关节的步态、姿态切换和跳跃共用 HAL 的 `JOINT_COMMAND_SLEW_RAD_S`，目前为 10.47 rad/s。跳跃测试保留原轨迹及验收标准，以便测量限速对跳跃的影响。

轮式转向时，四个轮毂共用一个附加扭矩上限，由髋俯仰关节当前的最低可用扭矩与腿部力臂估算。髋俯仰或膝关节偏离目标时会进一步降低轮毂输出，松开转向键后限幅保持 1 秒以覆盖制动。

## STM32F407

- 足式使用 ICM42688P 的重力方向计算轮胎触地点。低速承重估计可用时，从至少三个支撑点估计坡度。承重数据不足时用 IMU 做限幅的姿态补偿。足式和轮式的承重标定分别填在 HAL 的 `Foot_mode_control.c`，用对应模式下悬空与实际承载的髋俯仰、膝关节力矩进行校准。标定完成后分别启用 `FOOT_TERRAIN_CONTACT_CALIBRATED` 和 `WHEEL_TORQUE_CONTACT_CALIBRATED`。
- 遥控器第 10 通道（`CLIMB_SBUS_CHANNEL = 9`）切至高档选择爬坡。SWA 为高档且 SWC 为四足中档时，进入足式爬坡。退出高档后恢复 SWB 选择的普通步态。首次收到的高档需要回到低档再切换。
- 达妙轮毂使用速度模式，底盘轮速上限为 10 rad/s。轮式转向保护读取腿部编码器，按跟踪误差降低四轮目标速度。
- 灵足关节指令上限以 EduLite05 在 48 V、1.8 N·m 下的额定输出转速 100 rpm 为基准，约 10.47 rad/s。HAL 在 200 Hz 下每周期最多改变约 0.05236 rad。跳跃触发时会校验各阶段关节角和峰值速度。原蹬腿轨迹的目标峰值约 23.2 rad/s，超过该指令上限。
- Keil 入口为 `HAL/RCS_Template_F407/MDK-ARM/RCS_Template_F407.uvprojx`。实机使能取决于电机 ID、方向、零位、机械限位和轮径标定。当前工程的驱动与承重标定开关为零。

## 自动回归检查

把世界复制到同一 `worlds` 目录，并在副本的机器人节点里添加相应的 `controllerArgs`。保留 Supervisor，测试会在结束后自动关闭这个 Webots 实例。结果文件写到控制器运行目录。

| 参数 | 检查内容 |
| --- | --- |
| `[ "--smoke-test" ]` | 500 组轮心正逆解、1500 组触地点正逆解、站立、步态状态、四足与轮式切换、折叠与展开、急停和关机。 |
| `[ "--lateral-left" ]` 或 `[ "--lateral-right" ]` | 横移方向、距离和机身姿态。 |
| `[ "--jump-test" ]` | 要求连续离地至少 200 ms、机身比下蹲前抬升至少 65 mm、落地点比起跳点向前至少 16 cm。前后轮接地时间差不超过 30 ms，接地后前后位移不超过 8 cm，并在 2 秒内恢复站姿。跳跃日志也记录右前髋俯仰和膝关节的扭矩反馈与限值。 |
| `[ "--drive-test" "walk" ]` | 实测前后位移或转角。可用 `climb`、`walk`、`trot`、`pronk`、`gait-back`、`gait-left`、`gait-right`、`wheel-front`、`wheel-back`、`wheel-left`、`wheel-right`。轮式左右转检查关节最大跟踪误差。`climb` 从按 `3` 启动，检查前进、单腿摆动、接地和逆解。 |
| `[ "--model-test" ]` | 在无重力的副本中运行，将机器人放到离地约 0.5 m。逐个驱动并读取 16 个电机，根据实测轮心和轮轴分别校验轮心与触地点正解。可给机器人设置非零横滚和俯仰再运行一次。 |
