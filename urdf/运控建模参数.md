# 运控建模参数 · 轮足四足机器狗 v11.1

> 用途：给运动控制/仿真建模用。**这是简化运动学参数**，不是机械图纸。
> 版本：v11.1（2026-11-21）。后续若机体尺寸变更，只需改本文件的「髋关节矩形」与「偏置」两项。

---

## 1. 一句话给运控

**四连杆不用建。** 膝关节虽然是"电机在髋 + 曲柄连杆"，但它是严格平行四边形，`i ≡ 1`：
电机转 1° = 膝转 1°，力矩 1:1。所以 URDF 里直接把 KFE 建成**膝上的一个铰链**即可，
只多一个零位映射：`电机角 = 180° − β`。

## 3. 关节定义（URDF 用）

| 关节 | 类型 | 轴 | 位置 | 限位 |
|---|---|---|---|---|
| HAA | revolute | **x** | (±115, ±74.5, 0) | ±15° |
| HFE | revolute | **y** | (±170, ±95, 0) | 大腿角 θ₁ ∈ [**15.7°, 69.1°**]（相对竖直向下） |
| KFE | revolute | **−y** | 膝（thigh 末端） | 大腿与小腿夹角 β ∈ [**55°, 145°**]，KFE 电机角 = 180° − β ∈ [35°, 125°] |
| WHEEL | continuous | **y** | 轮心（shank 末端） | — |

**零位建议**（重要，否则运控初始姿态对不上）：
- β = 135° 时：大腿前倾 **23.73°**、小腿后倾 **21.27°**、轮心在髋正下方 180.1 mm。
- KFE 电机零位约定为 β=180°（腿伸直），因此上电时电机读数 ≈ 45°。

## 4. 三条建模提醒

1. **HAA 与 HFE 不同轴**：两轴在 x、y 各偏 55 / 20.5，正交但**不相交**。如果直接用"三轴交于一点"的教科书模型，外摆时轮心会算错 `|HW|·sinψ` 的横向位移（ψ=15° 时约 48 mm）。
2. **KFE 与 HFE 同轴**（都在髋轴上），所以 KFE 的电机惯量要挂在 HFE 的父连杆上；但关节输出在膝上（i≡1）。
3. **轮心在髋正下方是"标称姿态"，不是几何必然**。β 一变，`|HW|` 就变：β=55° → 90.4 mm，β=145° → 185.9 mm。别把腿长写成常数 180。
