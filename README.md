# Webots 四足机器人仿真控制

> 基于 Webots 与 C 语言实现的 12 自由度四足机器人控制器，完成步态生成、足端轨迹规划、运动学求解和机身姿态修正，并在仿真环境中驱动 4 条腿共 12 个关节运动。

## 项目定位

本项目面向四足机器人运动控制的学习与验证。控制程序运行在 Webots 仿真环境中，以 10 ms 为控制周期读取 IMU 姿态信息，生成各腿足端目标位置，求解关节角度并下发给电机。

仿真世界文件位于 `worlds/my_firstwebots.wbt`，核心控制器位于 `controllers/my_controller`。

## 核心功能

- 实现对角小跑（Trot）、慢走（Walk）和四腿同步跳跃（Pronk）等步态的生成与切换。
- 采用每腿独立状态机管理保持、支撑、摆动、收腿、展开和异常等运动状态。
- 使用三次贝塞尔曲线生成摆动阶段的足端轨迹，并通过查表插值降低实时计算量。
- 实现几何法逆运动学、雅可比迭代逆运动学及自动降级求解入口，同时提供正运动学与雅可比速度、力映射。
- 基于 IMU 的 pitch、roll 数据设计 PD 姿态控制，在支撑腿足端高度上叠加修正量以维持机身水平。
- 支持跳跃阶段控制、遥控输入处理和通信帧编解码模块。

## 控制流程

```text
IMU / 速度指令
      ↓
步态生成器 → 步态调度器 → 腿部状态机 × 4
      ↓                         ↓
姿态 PD 修正              足端轨迹与逆运动学
      ↓                         ↓
              12 个关节电机目标角度
```

## 技术要点

| 模块 | 实现内容 |
| --- | --- |
| 步态控制 | 按全局相位分配每条腿的支撑相与摆动相，并协调状态切换。 |
| 轨迹规划 | 使用三次贝塞尔曲线规划摆动足端的抬升与落脚过程。 |
| 运动学 | 建立 3 自由度单腿正、逆运动学模型，处理工作空间和关节限位。 |
| 稳定控制 | 由 IMU 姿态反馈驱动 PD 修正，减小俯仰和横滚偏差。 |
| 软件结构 | 将步态、状态机、运动学、姿态控制和全局状态拆分为独立 C 模块。 |

## 运行方式

1. 使用 Webots 打开 `worlds/my_firstwebots.wbt`。
2. 确认机器人控制器为 `my_controller`。
3. 运行仿真；Webots 会编译并启动控制器。

也可在安装并配置好 Webots 开发环境后进入 `controllers/my_controller` 执行 `make` 编译。
